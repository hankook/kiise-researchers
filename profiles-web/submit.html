연구자 검색

프로필 등록 안내

아래 항목을 구글 폼으로 제출해 주시면, 제출 내용이 그대로 웹 프로필 한 페이지로 구성됩니다. 같은 페이지에서 인쇄 / PDF 저장을 누르면 기존 브로셔와 동일한 A4 세로 1면 PDF가 만들어집니다.

분량 기준: 항목별로 한 줄에 한 항목씩 입력해 주세요. 줄바꿈이 그대로 불릿 하나가 됩니다. 전체 분량이 A4 1면을 넘으면 인쇄 시 2면으로 나뉘므로, 각 항목 3~5줄을 권장합니다.

등록 절차

  1. 제출 — 아래 항목을 구글 폼으로 작성해 주세요. 2~3분이면 충분합니다. GitHub 계정은 필요하지 않습니다.
  2. 확인 — 담당 간사가 소속·직위를 학과 공식 홈페이지와 대조하여 확인합니다. 기관 도메인 이메일로 제출해 주시면 확인이 빠릅니다.
  3. 승인 — 미디어홍보위원 검토 후 승인된 프로필만 게시됩니다. 보통 1~2주가 소요되며, 게시되면 메일로 알려 드립니다.
  4. 게시 — 승인 즉시 브로셔 페이지에 자동 반영됩니다.
수정·삭제는 등록하실 때 적어 주신 이메일로 담당자에게 요청해 주세요. 본인 확인 후 처리합니다. 게시된 내용에 문제가 있다는 신고가 접수되면, 사실 확인이 끝날 때까지 해당 프로필을 일시 비공개로 전환합니다.

담당자 안내 — 접수 후 반영 절차

  • 구글 폼 응답을 CSV로 내려받습니다. (원본 CSV는 저장소에 커밋하지 않습니다)
  • 소속·직위를 학과 공식 홈페이지와 대조해 본인 확인을 합니다.
  • 사진·그림 파일은 각각 photos/, figures/ 폴더에 넣고 파일명을 정리합니다.
  • python3 tools/build.py import 응답.csv --merge 로 데이터를 변환합니다.
  • python3 tools/build.py check 로 누락 항목·사진 파일·소사이어티 표기를 점검합니다.
  • 브랜치를 올려 Pull Request 를 만들고, 검토위원 승인 후 머지하면 자동 배포됩니다.
  • 문제가 제기된 프로필은 "visible": false 로 즉시 비공개 전환할 수 있습니다.
  • 전체 운영 방침은 저장소의 OPERATIONS.md를 참고하세요.
