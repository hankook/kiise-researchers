# inbox — 여기에 올리면 사이트에 반영됩니다

교수님께 메일로 받은 **등록 양식(xlsx)과 사진**을 이 폴더에 올리면,
1~2분 뒤 자동으로 프로필이 만들어지고 사이트에 게시됩니다. 처리가 끝난 파일은 이 폴더에서 저절로 지워집니다.

> 올리기 전에 **본인 확인**을 먼저 해 주세요. 소속 기관 메일(`@*.ac.kr` 등)에서 온 메일인지,
> 학과 홈페이지 교원 목록과 성명·직위가 맞는지. (`OPERATIONS.md` 2장)

## 올리는 방법

1. 이 화면 오른쪽 위 **Add file → Upload files**
2. 메일에서 내려받은 **양식 파일과 사진(그림)** 을 끌어다 놓기
3. 아래 **Commit changes** 클릭 (기본 선택인 *Commit directly to the main branch* 그대로)
4. 저장소 위쪽 **Actions** 탭에서 `프로필 반영 및 배포` 가 초록색 ✓ 이 되면 끝

**한 번에 한 분씩** 올리면 양식과 사진을 자동으로 짝짓습니다.
여러 분을 한꺼번에 올릴 때는 **사람별 폴더**에 넣어 폴더째 끌어다 놓거나,
양식의 '사진 파일명' 칸에 첨부 파일 이름이 정확히 적혀 있어야 합니다.

## 수정

교수님이 고친 양식을 다시 보내시면 똑같이 올리면 됩니다.
양식의 **E-mail 이 같은 기존 프로필**을 찾아 고칩니다. 사진을 다시 보내지 않으셨으면 기존 사진이 유지됩니다.

## 비공개 · 공개 · 삭제

**Add file → Create new file** 로 `요청.txt` 를 만들고 한 줄에 하나씩 적은 뒤 Commit 합니다.

```
비공개 kim-jeongbo
공개 kim-jeongbo
삭제 kim-jeongbo
```

프로필 id 는 사이트 주소 `profile.html?id=…` 의 값입니다. 성명으로 적어도 되지만, 같은 이름이 있으면 id 로 적어야 합니다.
**비공개**는 내용을 저장소에 남겨 두고 사이트에서만 내립니다. **삭제**는 데이터와 사진을 지웁니다 (게시 동의 철회 등).

## Actions 가 빨간색 ✗ 이면

문제가 있어 **아무것도 바꾸지 않은** 상태입니다. 사이트는 이전 그대로입니다.

1. Actions 탭에서 실패한 실행을 눌러 **Summary** 의 표를 봅니다. 예) `연구 키워드 4개 (5~10개 필요)`
2. 교수님께 고쳐 달라고 회신하거나, 직접 고친 파일을 **같은 이름으로** 다시 올리면(덮어쓰기) 자동으로 다시 시도합니다.
3. 필요 없는 파일은 이 폴더에서 지웁니다 (파일 열기 → ⋯ → Delete file).

| 자주 보는 메시지 | 조치 |
|---|---|
| 연구 키워드 N개 / 한마디 N자 / ○○ 없음 | 양식 내용 보완 |
| 공식 목록에 없는 소사이어티·연구회 | 양식의 '소사이어티 목록' 시트에 있는 이름 그대로 |
| '공개 동의' 칸에 '동의'가 없습니다 | 동의 없이는 게시하지 않습니다. 교수님께 확인 |
| 어느 양식의 이미지인지 알 수 없습니다 | 한 분씩 올리거나, 사람별 폴더에 넣거나, '사진 파일명' 칸 확인 |
| 이미지를 열 수 없습니다 | JPG·PNG 로 다시 보내 달라고 요청 |
| 이름·소속이 같은 프로필(○○)이 이미 있는데 E-mail 이 다릅니다 | 같은 분이면 양식의 '프로필 id' 칸에 그 id 를, 다른 분이면 새 id 를 적어서 다시 올림 |
| 예전 엑셀 형식(.xls) | xlsx 로 저장해서 다시 |
