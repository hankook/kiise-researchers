# inbox — 여기에 올리면 사이트에 반영됩니다

본인 확인을 마친 등록 메일의 **양식(xlsx)과 사진**을 이 폴더에 올리세요.

1. 오른쪽 위 **Add file → Upload files** → 파일을 끌어다 놓고 **Commit changes**
2. **Actions** 탭에서 초록색 ✓ 이 되면 사이트에 게시된 것입니다. 처리한 파일은 이 폴더에서 저절로 지워집니다.

비공개·삭제는 `요청.txt` 에 `비공개 프로필id` 처럼 적어 올립니다.
빨간색 ✗ 이면 아무것도 바뀌지 않은 상태입니다. 자세한 내용은 저장소 첫 화면의 README 를 보세요.
